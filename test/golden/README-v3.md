# Synthetic NRPT v3 golden fixture (cross-implementation)

`synthetic-2page-v3.nrpt` (432 bytes, SHA-256
`4f6fd501d417842f641df4da586d2c4752521134d8a0f295e06d69e9e786823f`) is a **synthetic** NRPT v3
profile generated by the reference encoder
`NootedRedTool/Sources/NootedRedTool/ProfileCodec.swift` (`ProfileCodec.encode`) from this model:

| Page | mode | pageFileOffset | pageHash | image | pageVmOffset | Sites |
| --- | --- | --- | --- | --- | --- | --- |
| 0 | PAGE | `0x2000` | `0x1111222233334444` | 0 standalone | `0x2000` | `0x0100`: `112233` -> `112244` |
| 1 | DYLD | `0x87000` | `0xAAAABBBBCCCCDDDD` | 1 shared cache | `0x1000` | `0x0160`: `83e0fe` -> `83c801`; `0x0200`: `750b` -> `eb0b` |

Images: `/System/Library/Extensions/SyntheticGL.bundle/Contents/MacOS/SyntheticGL` (kind 0,
unslid `0`, vmsize `0x5000`) and
`/System/Library/Extensions/SyntheticMTL.bundle/Contents/MacOS/SyntheticMTL` (kind 1, unslid
`0x7FFB00000000`, vmsize `0x4000`). Header: build `24H232`, APUMask `0x28`, DeviceID `0x1638`.

It contains no Apple bytes. It pins cross-implementation parity for the NRPT v3 header, 32-byte
page records (mode/imageIndex/pageVmOffset), image table and payload checksum: the independent
Python validator must decode it to the same model and re-encode it byte-identically (verified
against the Swift reference codec).

Older `synthetic-2page.nrpt` (v1), `synthetic-2page-v2.nrpt` (v2) and `engine-crosscheck/` are
historical round artifacts; the v3 validator rejects v1/v2 with `E003` and does not use them.
